# Print assets

`qr-nimblebeaver-solver.{png,svg}` encode **https://nimblebeaver.com/solver**,
a Shopify URL redirect that forwards to the Vercel deployment of this solver.
Printing the redirect (not the Vercel hostname) means the QR on the puzzle
never has to change if hosting moves. Error-correction level H, 1200 px PNG.
Keep a quiet zone of at least 4 modules of white around the code when printing.
